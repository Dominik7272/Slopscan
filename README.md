## Setup

Clone the repo
```bash
git clone https://github.com/Dominik7272/Slopscan.git
```

Install requirements and download the model
```bash
pip install -r requirements.txt
pip install huggingface_hub
hf download Dominik72/Slopscan-Anime best.pt --local-dir .
```

`torch`/`torchvision` from PyPI are CUDA builds. On a CPU-only machine install them
from the PyTorch CPU index instead.

## Usage

```python
from slopscan import Slopscan

clf = Slopscan("best.pt")           # model path, loaded once, GPU if available
print(clf.classify("image.png"))    # P(AI generated), 0..1
```

`classify` accepts a path or an already-open `PIL.Image`. Or run the example script:

```bash
python classify.py
```
